# Qwen4Exp Server P1 接入结果

Qwen4Exp NF4 的普通 T1 已贯通 LoadedModel → Session/Request → Worker IPC → HTTP JSON/SSE。实施跨越 10 月 6 日至 7 日。MTP 的 draft/verify/commit 尚未进入 Server；此前 20.59289022 tok/s 是独立 MTP 探针成绩。

两个 DeepSeek V4.1 Flash 子代理分别实施 session 内存契约和 Worker/协议/HTTP 接线。主代理实施 shared loader、共享 greedy、真实 session 验收，并复查、修正和联调子代理改动。

## 已实现

- shared loader 使用 Q4E 独立 family 分支及 lazy mmap。首次真实运行发现普通 eager loader 会试图上传全部 131 个分片；现已改用 CLI 的 LoadModelWeightsLazy。
- 模型权重、专家缓存和执行 scratch 由 LoadedModel 持有，session 独占 KV、indexer、GDN/conv 和 PLE。CacheBytes 返回真实设备 payload，预算在创建 session 前检查。IPC 保持 maxRecurrentSnapshots=0。
- 新增 qwen4exp_nf4 backend、qwen4exp_nf4_bf16_kv capability，以及 Worker/Client 工厂入口。跨 session decode batch 的 key 为 null，模板编译期排除不支持的 batch 调用。
- Q4E 必须使用 tokenizer 中的 checkpoint chat template；缺失时明确报错。
- 两阶段 BF16 greedy 移入 src/ops/GreedyOps.hpp，T1 与探针共用最低 token ID 的 tie 规则和全量 finite 检查。scratch 在 model load 时分配。

## 聚焦验收

| 检查 | 结果 |
|---|---|
| 内存预留、协议、Worker CPU | 3/3 通过 |
| Server Chat、Client、Pipe CPU | 全部通过；Pipe 在更新 fake Worker 后单独重跑通过 |
| 共享 greedy | B1/B2/B4、并列最大值、NaN/Inf、越界 canary 通过，USM 不增长 |
| 真实 shared session，C=128，S=0 | 两 session 交错 logits/greedy 一致；第二轮追加、Reset、Truncate、预算拒绝、先释放 model/runtime 后继续使用 session 均通过；结束后显式 USM=0 |
| 真实 HTTP，C=512 | health/参数校验、24-token JSON/SSE 输出与 usage 一致，24 个内容帧、正常回收和优雅退出 |
| fake HTTP | health、JSON/SSE、断连隔离另一请求，共 3 项通过 |

真实 HTTP 使用 20-token 的短 prompt，生成 24 tokens；与原 1833-token MTP 性能 prompt 不同。第一次 JSON 请求约 38.9456 秒，随后 SSE TTFT 约 0.7896 秒、总时延约 2.2237 秒。这是带冷/热差异的功能验收数据，不作为 decode 吞吐结论。health 测试产生的 7 个 failed 计数来自预期的无效参数请求；3 个合法生成请求均完成。

C=2048 的 session 预留为 device 176234496 bytes、S=0 host 117669888 bytes；S=4 host 为 589824000 bytes。真实服务的 C=512 预留也由 health/report 返回。它们是显式 payload，不是 WDDM/RSS。

## 启动

仓库根目录，沿用本轮保存的 Worker 配置：

~~~powershell
$settings = Get-Content docs/plans/qwen38-server-p1-2026-10-07.json -Raw | ConvertFrom-Json
foreach ($entry in $settings.worker_environment.PSObject.Properties) {
    [Environment]::SetEnvironmentVariable($entry.Name, [string]$entry.Value, 'Process')
}
./build-refactor-server/AilaServer.exe --worker ./build-refactor/AilaWorker.exe --model C:/QwenModels/Qwen3.8-Flash-Next-BNB-NF4-v2 --backend qwen4exp_nf4 --context 2048 --sessions 2 --decode-batch-size 1
~~~

配置含本机 profile 路径；迁移机器时修改该路径并重新测量。默认 HTTP model id 为 qwen4exp，端口为 8080。Server 保持独立 MSVC 构建，SYCL 只在 Worker。

## 后续边界
