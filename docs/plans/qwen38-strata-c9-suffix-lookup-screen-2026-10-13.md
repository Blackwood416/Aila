# Strata C9 筛选：suffix-lookup drafter — NO-GO（离线门未过）

日期：2026-10-13。范围：扫描文档 C9 的离线探针（门：接受率上界 > 0.5 且平均 token/窗口 > 1.5）。

## 1. 方法

`tmp/q4e-strata-c9/lookup_probe.py`：对真实 token 流建 3-gram 索引（同一 3-gram 记 4 个最近出现，
取"早于当前后缀"的最近一次，避免自匹配），每个位置提议最多 K 个 token，与真实续写比对得到
**接受前缀长度**（贪心解码下即精确匹配上界）。

## 3. 判定

1. **门未过**：接受率 32-36% < 50%（token/窗口 1.66-1.80 过线）。K 增大只降接受率、几乎不加
   token/窗口 → 提议长度已过最优。
2. **前置缺失**：C9 的收益必须由"多行 verify 窗口"兑现，而 Aila 当前没有可信的多行路径
   （MTP 等价门未过、`--decode-batch-size 1`）；Strata 自己测到"suffix-only 接受率 ~9%、不如 MTP"，
   且在 A770 上"草稿与 verify 重叠"是负收益（`--spec-split` 变慢）。
3. 本样本是**文档自重复**的上界形态（真实 agent 代码编辑会更高，但需要真实语料才能证明），
   即便如此也未达 50% 门 → **NO-GO**。
4. **重启条件**：出现可信的多行 verify 路径 + 真实编辑/引用型语料（PI agent 的工具回合转录）；
   届时用同一脚本在真实语料上复测，并遵守 C8 的 3% 发射规则。
